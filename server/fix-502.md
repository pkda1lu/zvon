# Исправление ошибки 502 Bad Gateway

Ошибка 502 Bad Gateway означает, что Nginx не может подключиться к Node.js серверу на порту 5000.

## Быстрая диагностика

Выполните на сервере:

```bash
# 1. Проверьте, запущен ли Node.js сервер
pm2 list

# 2. Проверьте, слушает ли порт 5000
netstat -tlnp | grep :5000
# или
ss -tlnp | grep :5000

# 3. Проверьте логи
pm2 logs
sudo tail -50 /var/log/nginx/error.log

# 4. Проверьте конфигурацию nginx
sudo nginx -t
```

## Возможные причины и решения

### 1. Сервер Node.js не запущен

**Решение:**
```bash
cd /var/www/zvon/server
pm2 restart ecosystem.config.js
# или
pm2 start ecosystem.config.js
```

### 2. Сервер упал из-за ошибки

**Решение:**
```bash
# Проверьте логи
pm2 logs --lines 50

# Перезапустите
pm2 restart all

# Если не помогает, перезапустите с очисткой логов
pm2 delete all
pm2 start ecosystem.config.js
```

### 3. Порт 5000 занят другим процессом

**Решение:**
```bash
# Найдите процесс на порту 5000
lsof -i :5000
# или
fuser -k 5000/tcp

# Затем перезапустите сервер
pm2 restart all
```

### 4. Проблема с конфигурацией nginx

**Решение:**
```bash
# Проверьте конфигурацию
sudo nginx -t

# Если есть ошибки, исправьте их
sudo nano /etc/nginx/sites-available/zvon

# Перезагрузите nginx
sudo systemctl reload nginx
```

### 5. Проблема с переменными окружения

**Решение:**
```bash
# Проверьте .env файл
cat /var/www/zvon/server/.env

# Убедитесь, что все переменные установлены:
# - PORT=5000
# - MONGODB_URI=...
# - JWT_SECRET=...
# - CLIENT_URL=...

# Перезапустите сервер
pm2 restart all
```

### 6. Проблема с MongoDB

**Решение:**
```bash
# Проверьте статус MongoDB
sudo systemctl status mongod

# Если не запущен
sudo systemctl start mongod

# Проверьте подключение
mongo --eval "db.adminCommand('ping')"
```

## Полная перезагрузка

Если ничего не помогает:

```bash
# 1. Остановите все
pm2 stop all
sudo systemctl stop nginx

# 2. Проверьте порты
netstat -tlnp | grep :5000

# 3. Запустите сервер
cd /var/www/zvon/server
pm2 start ecosystem.config.js

# 4. Запустите nginx
sudo systemctl start nginx

# 5. Проверьте статус
pm2 list
sudo systemctl status nginx
```

## Проверка работоспособности

```bash
# Локально на сервере
curl http://localhost:5000/api/health

# Через nginx
curl https://serverzvon.duckdns.org/api/health
```

## Автозапуск при перезагрузке

Убедитесь, что PM2 настроен на автозапуск:

```bash
pm2 startup
pm2 save
```
