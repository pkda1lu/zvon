# Компонент подключения для мини-аппки TikTok

Сюда кладётся бинарник **sing-box** — через него уходит трафик окна TikTok,
чтобы сервис видел зарубежный адрес вместо российского. Остальное приложение
(голос, LiveKit, сообщения) ходит напрямую, см. `public/tunnel.js`.

В репозитории бинарника нет намеренно: это стороннее приложение со своей
лицензией и своим циклом обновлений, и в истории кода ему делать нечего.

## Что положить

| Платформа | Файл |
| :--- | :--- |
| Windows | `sing-box.exe` |
| Linux / macOS | `sing-box` (с правом на запуск) |

Скачивается из релизов проекта sing-box (SagerNet), архив `windows-amd64`.
Из архива нужен ровно один файл — сам исполняемый.

При сборке папка целиком попадает в `resources/singbox/` рядом с приложением
(`build.extraResources` в `package.json`), а `tunnel.js` ищет её там же. Для
отладки без сборки можно указать путь переменной окружения:

```
set ZVON_SINGBOX=D:\tools\sing-box.exe
```

## Что нужно на сервере

Ссылки на узлы задаются переменными окружения Zvon-сервера — в базу и в выдачу
профиля они не попадают:

```
TIKTOK_OUTBOUND_DE=vless://uuid@de-node.example:443?security=reality&sni=...&pbk=...&fp=chrome&type=tcp
TIKTOK_OUTBOUND_FI=vless://uuid@fi-node.example:443?...
```

Вместо ссылки можно положить готовый JSON выходного подключения sing-box —
тогда доступен любой транспорт, включая те, что разбор ссылок не покрывает.
Страна без заданной переменной просто не показывается в выборе.
