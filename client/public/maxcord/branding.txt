Инструкция: что нужно сделать тебе

  Для того чтобы это заработало в «боевых» условиях, тебе нужно выполнить 3 простых шага в настройке твоего окружения:

  1. DNS-настройка
  Оба домена должны указывать на один и тот же IP-адрес твоего сервера.
   * zvonserver.ru -> A-запись -> IP сервера
   * maxcord.fun -> A-запись -> IP сервера

  2. Настройка Nginx (Reverse Proxy)
  Если ты используешь Nginx, тебе нужно, чтобы оба домена проксировали запросы на один и тот же порт твоего Node.js приложения (по умолчанию 5000).

  Пример конфига (можно сделать один server блок с двумя server_name):

    1 server {
    2     listen 443 ssl;
    3     server_name zvonserver.ru maxcord.fun;
    4
    5     # SSL сертификаты (рекомендую использовать Certbot для обоих доменов)
    6     # ...
    7
    8     location / {
    9         proxy_pass http://localhost:5000; # Порт твоего бэкенда
   10         proxy_set_header Host $host; # ВАЖНО: прокидываем заголовок Host
   11         proxy_set_header X-Real-IP $remote_addr;
   12         proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
   13         proxy_set_header X-Forwarded-Proto $scheme;
   14
   15         # Для работы Socket.io
   16         proxy_http_version 1.1;
   17         proxy_set_header Upgrade $http_upgrade;
   18         proxy_set_header Connection "upgrade";
   19     }
   20 }

  3. Обновление .env (необязательно)
  Если в .env на сервере жестко прописан CLIENT_URL или API_URL, убедись, что CORS в server.js теперь ориентируется на список разрешенных доменов (я уже добавил туда оба твоих домена).

  Как проверить:
   1. Зайди на maxcord.fun — ты увидишь логотип MAXCORD, заголовок вкладки "MAXCORD" и соответствующую иконку.
   2. Зайди на zvonserver.ru — ты увидишь стандартный Zvon.
   3. При этом база данных, пользователи и все API будут общими. Письма с кодом подтверждения будут приходить с названием того бренда, через который пользователь зашел.

  Система готова. Теперь проект — это настоящий "white-label", который можно масштабировать на любое количество доменов, просто добавляя их в BRANDS конфиг.
