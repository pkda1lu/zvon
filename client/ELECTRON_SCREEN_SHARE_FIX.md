# Исправление демонстрации экрана в Electron

## Проблема
Демонстрация экрана не работала в упакованной версии Electron из-за того, что стандартный `getDisplayMedia` API не работает с `file://` протоколом.

## Решение
Добавлена поддержка Electron `desktopCapturer` API с автоматическим fallback на стандартный `getDisplayMedia`.

## Изменения

### 1. Preload скрипт (`public/preload.js`)
- Экспортирует `desktopCapturer` API в безопасном контексте
- Используется для работы с захватом экрана в Electron

### 2. Обновлен `electron.js`
- Включен `contextIsolation: true` для безопасности
- Добавлен preload скрипт
- Настроены разрешения для захвата экрана

### 3. Обновлен код демонстрации экрана
- Автоматическое определение Electron окружения
- Использование `desktopCapturer` API в Electron
- Fallback на стандартный `getDisplayMedia` в браузере

### 4. Обновлен скрипт сборки
- Автоматическое копирование `electron.js` и `preload.js` в `build/`

## Как пересобрать

```bash
cd client
npm run electron:build
```

## Тестирование

1. Запустите собранное приложение
2. Подключитесь к голосовому каналу
3. Нажмите кнопку демонстрации экрана
4. Должен автоматически использоваться Electron `desktopCapturer` API
5. Экран должен начать транслироваться

## Отладка

Если демонстрация экрана все еще не работает:

1. Откройте DevTools (F12) в Electron приложении
2. Проверьте консоль на наличие ошибок
3. Убедитесь, что в консоли есть сообщение "Detected Electron environment, trying desktopCapturer API"
4. Проверьте настройки приватности Windows:
   - Параметры → Конфиденциальность → Захват экрана
   - Убедитесь, что приложение имеет разрешение

## Технические детали

- `contextIsolation: true` - безопасный режим Electron
- `preload.js` - скрипт, который выполняется до загрузки веб-страницы
- `desktopCapturer` - нативный API Electron для захвата экрана
- Автоматический fallback обеспечивает работу как в Electron, так и в браузере
