# Подробная игровая активность

Поддерживается настольным клиентом на Tauri. В браузере и старом Electron остаётся обычное обнаружение запущенной игры.

## Подключение

1. Открыть «Настройки → Активность → Подробная игровая активность».
2. Переключатель Dota 2 и Counter-Strike 2 включён по умолчанию. Если вы отключали его ранее, включить снова.
3. Нажать «Подключить» рядом с установленной игрой.
4. Для Dota 2 добавить `-gamestateintegration` в параметры запуска в свойствах игры в Steam.
5. Перезапустить игру. В настройках Звона появится «Данные от игры поступают».

Звон ищет Steam в реестре Windows, дополнительные библиотеки — в `steamapps/libraryfolders.vdf`, каталог игры — в её manifest-файле. Он создаёт только свой `gamestate_integration_zvon.cfg`, не меняет параметры запуска Steam и не затрагивает конфигурации других интеграций.

## Что отображается

- Dota 2: выбор героя, подготовка, матч, завершение, игровые часы и пауза, если игра её сообщает.
- CS2: фаза матча, карта, счёт и режим из поля `map.mode`.
- Главное меню — только при явном `player.activity = menu`.
- Турбо — при явном `game_mode/gamemode = 23`; рейтинг Dota — при явном `lobby_type = 7`. Эти поля могут отсутствовать в GSI: тогда показывается только состояние матча.
- CS2 `competitive` отображается как «Соревновательный»: из этого значения нельзя достоверно отличить Premier. «Премьер» выводится только для явного значения `premier`; `scrimcomp2v2` — «Напарники».
- При отсутствии подробных данных сохраняется обычная активность с названием игры.

## Поведение и приватность

Интеграция по умолчанию включена. Сохранённое пользователем отключение сохраняется. Установка конфигураций игр остаётся отдельным действием. Локальный приёмник привязан только к `127.0.0.1:29873`; для каждой установки создаётся случайный токен. Приёмник требует включения интеграции, правильного токена и совпадения App ID с маршрутом. Настройки видимости активности и выключение обнаружения по-прежнему действуют.

Сырые данные GSI не отправляются на сервер и не сохраняются: формируются только `state` и `details`. Steam ID, имя игрока и токен не входят в опубликованный статус. При отсутствии обновлений дольше 30 секунд подробности удаляются. Обновление состояния не сбрасывает время начала игровой активности.

Конфигурация ограничивает обновления интервалом 5 секунд и отправляет heartbeat каждые 10 секунд. HTTP-запросы ограничены 128 КиБ и 5 секундами, одновременные соединения — 16. Проверяются маршрут, длина тела и App ID; браузерные запросы с `Origin` отклоняются.

## Проверки

```powershell
cd client/src-tauri
cargo test --lib gsi::tests
cargo test --lib rich_activity_tests
```

Для проверки на реальной игре нужны установленная игра, конфигурация GSI и перезапуск игры. Синтетические тесты не доказывают, что конкретная версия игры отдаёт режим или состояние меню.
