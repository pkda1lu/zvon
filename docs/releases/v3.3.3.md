# Звон 3.3.3

## Новое

- **Папки серверов.** Объединяйте серверы в группы, раскрывайте их в боковой панели или включайте изоляцию, чтобы показывать только выбранную папку. У свёрнутых папок есть индикатор непрочитанных сообщений.
- **Коллекционные награды.** В профиле появилась коллекция с вращаемыми 3D-моделями, вариантами оформления и свойствами экземпляров. Модераторы могут выдавать и отзывать награды вручную или применять условия по дате регистрации и первого зафиксированного визита.
- **Награда как значок профиля.** В настройках рядом со своим значком и значком сервера появился раздел «Награды»: выберите одну из полученных наград для отображения рядом с ником. При отзыве награды значок снимается.
- **Новые модели наград.** Семь моделей, включая «Жук · Кодер», с обновлёнными материалами, освещением и деталями.
- **Уведомления о наградах.** Новые награды появляются в уведомлениях с карточкой и переходом к коллекции в профиле.
- **Подробная игровая активность.** Настольный клиент на Tauri может показывать состояние Dota 2, игровые часы, а для CS2 — карту, режим и счёт, когда эти данные доступны от игры.

## Интерфейс

- Всплывающие окна приведены к единому стилю по образцу «Вложений»: фон, рамки, скругления, заголовки и отступы.
- Кнопки закрытия оформлены одинаково и имеют подпись ESC. Escape закрывает внутреннее окно, сохраняя само приложение открытым.
- Основной экран стал компактнее: меньше промежутков между панелями, лишних рамок и свечения. Выделение чатов и каналов приведено к общей системе.
- В маленьком профиле отображается активность пользователя. Текст переносится без обрезки, увеличенный логотип игры расположен справа.
- Вернулась компактная строка заголовка мини-приложений с небольшими кнопками управления.
- Добавлены оформленные пустые состояния наград и сообщения о результате выдачи.

## Исправления

- Исправлена мобильная раскладка вложений, голосовых каналов и личных звонков.
- На мобильных добавлен раздел уведомлений и доступ к «Сообщить о проблеме» в настройках.
- Кнопки модерации на узких экранах переносятся под данные пользователя и не выходят за границы окна.
- Повышена устойчивость перехода из полноэкранной трансляции в мини-окно при переносе приложения между мониторами: упорядочено создание окна и исправлен расчёт позиции для разных масштабов экрана.

- Исправлена отрисовка нижней границы развёрнутого окна при запуске и восстановлении из трея, из-за которой могла появляться белая полоса.
- Счётчик непрочитанных сообщений текстового канала постоянно виден, а не только при наведении.
- Получателя награды можно выбрать из выпадающего списка с поиском по нику и имени. Выдача использует ID выбранного пользователя.
- Обновление подробностей игрового статуса не сбрасывает длительность игровой сессии; устаревшие подробности очищаются.
- Отключён автоматический показ проморолика «Звон 3.0» при входе.

## Подключение игровой активности

Подробная активность включена по умолчанию; ранее сохранённое отключение остаётся в силе. Для подключения игры откройте **Настройки → Активность → Подробная игровая активность** и нажмите **«Подключить»**.

Для Dota 2 дополнительно добавьте `-gamestateintegration` в параметры запуска Steam и перезапустите игру. Точный режим отображается только когда игра явно его сообщает: при недостатке данных Звон не угадывает рейтинг, Турбо или Premier.
