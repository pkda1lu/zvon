# Звон 3.4.2

- Добавили верификацию личных аккаунтов и сообществ. Заявку можно подать из настроек профиля или сервера, а переписка с модераторами доступна в «Моих обращениях».
- Модераторы могут запросить дополнительные подтверждения, одобрить или отклонить заявку. После одобрения рядом с именем появляется голубая розетка для аккаунта или бирюзовая для сообщества.
- Партнёрские серверы получили отдельные бейджи для стримеров, видеоигр, проектов и компаний.
