🆔 **Vlyne ID — один аккаунт на всё сразу**

Раньше каждый наш проект жил сам по себе: в боте была подписка, в Zvon — аккаунт, в настольном клиенте — код из шести цифр, который надо было откуда-то переписать. Теперь это одна учётная запись.

**Vlyne ID — это ваш аккаунт Zvon.** Ничего создавать и переносить не нужно, он уже есть. Логин и пароль те же.

**Что изменилось**

🤖 **В боте** — кнопка «Связать с Vlyne ID» в разделе «Моя подписка». Один вход — и подписка видна во всех приложениях Vlyne. Код привязки больше не нужен.

💻 **В Vlyne Client** — кнопка «Войти через Vlyne ID» вместо ввода кода. Вход открывается в браузере: пароль вводится на странице Vlyne ID, а не в приложении.

🛍 **В магазине Zvon** — экран привязки без кода. Вошли в боте через Vlyne ID — магазин сам увидит вашу подписку: тот же ключ, тот же трафик, та же рефералка.

**Почему так лучше**

🔑 Никаких новых паролей и кодов, которые надо переписывать.
👀 Видно, где вы вошли: список устройств и приложений — в личном кабинете.
🛑 Доступ отзывается одной кнопкой и обрывается сразу, а не «когда-нибудь истечёт».
🔒 Пароль не передаётся приложениям никогда. Они получают только то, что вы разрешили, и вы видите список перед тем, как нажать «Разрешить».

**Личный кабинет**

vlyneid.zvonserver.ru — история входов, устройства, подключённые приложения и выгрузка всех ваших данных одним файлом. Заметили чужой вход — завершаете сами, не дожидаясь поддержки.

**Разработчикам**

Свой сервис можно подключить к входу через Vlyne ID: заявка подаётся в кабинете разработчика, там же видно её состояние и переписку с модератором. Обычный OAuth 2.1 / OpenID Connect — подойдёт любая готовая библиотека. Подробности: vlyneid.zvonserver.ru/developers
