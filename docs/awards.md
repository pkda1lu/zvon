# Награды

В полном профиле доступна вкладка «Награды». Модераторы и администраторы создают награды в «Настройки → Модерация → Награды». Доступны процедурные модели кубка, медали и кристалла в стиле Звона: графитовый металл, серебристый объёмный знак Z со скруглениями и хвостиком сообщения, дымчатое стекло. Медаль повторяет силуэт фирменной иконки. Выбранный цвет применяется к небольшим акцентам. Модели вращаются мышью, касанием или стрелками клавиатуры; Home возвращает начальный ракурс. При отсутствии WebGL используется значок.

Ручная выдача и отзыв используют точное имя пользователя. Автоматические условия: регистрация до даты и первый зафиксированный визит до даты. Граница исключительная: начало выбранного дня по Москве. Для регистрации до 2026 года выбирается 01.01.2026.

Условия проверяются при открытии вкладки наград. «Выдать всем по условию» применяет условие к существующим аккаунтам сразу, пакетами по 200. Повторные запросы не создают дубликаты. Отзыв сохраняется и препятствует автоматической повторной выдаче; ручная выдача снимает отзыв. Отключение условия сохраняет уже выданные награды.

Визиты фиксируются с момента установки функции по авторизованным запросам. Прошлые входы не восстанавливаются из даты регистрации. Боты и удалённые аккаунты исключаются. Награды учитывают блокировки и настройки видимости полного профиля.

Данные хранятся в отдельных коллекциях Award, AwardGrant и AwardVisit; mongoose создаёт их при использовании. Нужны уникальные индексы AwardGrant(user, award) и AwardVisit(user), объявленные в моделях. Изменения модераторов фиксируются в глобальном журнале.

## Коллекционное оформление

У экземпляра есть палитра модели (6 вариантов), фон (6), узор (4) и покрытие (3). Модератор задаёт каждое свойство коллекции или выбирает «Случайно для каждого владельца». Случайные свойства независимо выбираются на сервере при первой выдаче и сохраняются в AwardGrant.collectible. Отзыв, повторная выдача и автоматическая проверка не меняют оформление. Сочетания могут повторяться: это свойства экземпляра, а не гарантия единственного сочетания в коллекции.

Старые экземпляры получают воспроизводимое оформление на основе своего ID при первом чтении; оно сохраняется в базу без изменения даты выдачи. Номер экземпляра — полный уникальный ObjectId, записанный в base36, без усечения. Это идентификатор, а не порядковый номер выпуска.

Карточка показывает фон и узор за вращаемой моделью. «Свойства экземпляра» раскрывает названия палитры, фона, узора и покрытия. Предпросмотр в модерации помечен как пример и не определяет будущие случайные свойства. Проценты редкости и стоимость не назначаются.

Проверки: `node --test tests/awards.test.js tests/awards-routes.test.js tests/award-collectibles.test.js` из server; `npm run build` из client. HTTP-тесты используют подставные данные без живой MongoDB.
