# Документы по 152-ФЗ

## Публикуемые документы

Лежат в **`server/legal/`**, а не здесь:

| Документ | Файл | Где виден пользователю |
|---|---|---|
| Политика обработки персональных данных | `server/legal/politika-obrabotki-pd.md` | страница `/policy` |
| Согласие на обработку персональных данных | `server/legal/soglasie-na-obrabotku.md` | страница `/consent` |

Почему внутри `server/`, а не в `docs/`: сервер отдаёт эти файлы напрямую, и
путь за пределы своего дерева делал бы публикацию зависимой от того, копирует ли
развёртывание соседние папки. Так документы всегда едут вместе с кодом.

**Правки этих файлов сразу меняют то, что видит пользователь.** После
содержательного изменения нужно поднять версию в `server/utils/pdDocuments.js`
(`POLICY_VERSION`, `CONSENT_VERSION`) — иначе разные редакции запишутся в
согласия под одним номером, и доказать, с какой формулировкой согласился
конкретный человек, будет невозможно. Контрольная сумма пересчитывается сама.

## Что кодом не закрывается

Уведомление Роскомнадзора об обработке и отдельно о трансграничной передаче,
назначение ответственного, модель угроз и определение уровня защищённости по
ПП-1119, меры по приказу ФСТЭК России № 21, договоры с обработчиками, регламент
реагирования на инциденты (24 и 72 часа), обучение сотрудников.

Соответствие 152-ФЗ — состояние организации, а не свойство программы.
